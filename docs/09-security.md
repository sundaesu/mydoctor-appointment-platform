# Security

## Security Goals

- Protect patient information
- Enforce role-based access
- Limit visibility of sensitive data to the right role
- Keep clinic operations secure without making common workflows slow

## Initial Concerns

- Authentication for patients, doctors, and receptionists
- Access control across clinics and roles
- Privacy of patient identifiers and medical-adjacent data
- Auditability for operational actions such as queue changes and appointment updates

## Status

Specific security architecture is open and should be documented before implementation begins.
