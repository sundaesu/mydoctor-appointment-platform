# Decision Tracking

Architectural and important product decisions will be recorded as ADRs in this directory.

## Naming

Use names like:

- `ADR-001-...`
- `ADR-002-...`

## Required Sections

Each ADR should eventually contain:

- Context
- Decision
- Alternatives considered
- Reason
- Consequences
- Status
