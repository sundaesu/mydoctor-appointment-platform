# Notifications

## Notification Role

Notifications are an important part of the product because appointment confirmation, queue movement, and doctor delay updates should reach users without requiring constant manual checking.

## Likely Notification Events

- Appointment confirmation
- Token generation
- Queue progress
- Doctor delay
- Appointment reschedule
- Appointment cancellation

## Open Questions

- Which channels should be supported first
- Whether WhatsApp should be part of the initial release
- How notification preferences should be managed

## Status

Notification channel selection and delivery architecture are open decisions for a later phase.
